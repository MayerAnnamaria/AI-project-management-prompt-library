# AI Project Management Prompt Library

A practical library of **AI-assisted prompts, frameworks, and workflows for IT project management**.

The repository is designed to support faster, more structured work across planning, risk management, reporting, stakeholder communication, governance, and project delivery.

> **AI supports project-management decisions. The Project Manager remains accountable for the final output.**

## How to Use the Playbook

1. Identify the project-management task.
2. Open the relevant folder.
3. Select the appropriate prompt or workflow.
4. Replace placeholders with verified project context.
5. Run the prompt.
6. Review and correct the output.
7. Use the result only after appropriate human validation.

Recommended flow:

```text
Project Data
↓
AI Draft / Analysis
↓
Human Review
↓
Correction
↓
Decision / Approval
```

## Prompt Design Principle

Most prompts follow a simple structure:

```text
ROLE

TASK

CONTEXT

REQUIRED ANALYSIS

OUTPUT FORMAT

QUALITY RULES
```

Example:

```text
ROLE

You are a senior IT Project Manager.

TASK

Audit the project risk register.

CONTEXT

[PASTE VERIFIED PROJECT CONTEXT]

CHECK FOR

- vague risks,
- weak mitigations,
- missing owners,
- missing triggers,
- important dependencies.

OUTPUT

Risk ID
Issue Found
Recommendation
Priority

QUALITY RULE

Do not invent missing project facts.
State assumptions explicitly.
```

---

## AI Governance Rules

Before using AI:

- protect confidential information,
- use approved tools,
- remove unnecessary sensitive data.

Before using AI output:

- verify facts,
- verify dates and numbers,
- check assumptions,
- verify contractual or technical claims,
- obtain specialist review where required.

Never treat AI-generated content as automatic project truth.
