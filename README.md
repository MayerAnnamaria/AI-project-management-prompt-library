# AI Project Management Prompt Library

A practical library of **AI-assisted prompts and workflows for IT project management**, designed to support structured analysis, decision-making, governance, communication, and delivery.

> **AI supports project decisions. The Project Manager remains accountable for the final output.**

| Area | Practical Use |

| **Framework** | Prompt design, reusable templates, quality principles |
| **Project Initiation** | Charter, project brief, scope, objectives, assumptions |
| **Project Planning** | WBS, RACI, scheduling, estimates, procurement, communication |
| **Risk & Issue Management** | Risk identification, analysis, response planning, issue tracking |
| **Reporting & Communication** | Status reports, steering papers, dashboards, meeting minutes |
| **Commercial & Governance** | Contract review, changes, scope gaps, supplier evaluation, close-out |
| **Stakeholder Management** | Stakeholder analysis, engagement, change communication, feedback |
| **Advanced AI Workflows** | Chain prompting, role-based review, iterative refinement, document audit |
| **AI Governance** | Confidentiality, hallucination control, verification, responsible AI use |

## How to Use

1. Identify the project-management task.
2. Open the relevant prompt or workflow.
3. Replace placeholders with verified project context.
4. Run the prompt in an approved AI tool.
5. Review facts, assumptions, risks, and recommendations.
6. Apply the appropriate project approval process.

```text
Project Data
     ↓
AI Analysis / Draft
     ↓
Human Review
     ↓
Decision / Approval
```

## Advanced AI Workflows

The library goes beyond standalone prompts by combining AI tasks into reusable PM workflows.

**Chain Prompting**

```text
Project Brief → Risk Register → Response Plan → Status Report
```

**Role-Based Review**

```text
Draft → Reviewer Perspective → Challenge → Improved Draft
```

**Iterative Refinement**

```text
Draft → Critique → Rewrite → Final Review
```

**Document Audit**

```text
Document → Gap Analysis → Correction → Re-Audit
```

## AI Governance

Before using AI:

- protect confidential and personal information,
- use approved tools,
- provide only necessary project context.

Before using AI output:

- verify facts, dates, and calculations,
- distinguish assumptions from confirmed information,
- verify contractual and technical claims,
- obtain specialist review where required.

**AI-generated content should never be treated as automatic project truth.**

## Purpose

This repository demonstrates practical AI use for:

- project planning,
- risk management,
- decision support,
- governance,
- stakeholder communication,
- quality assurance.

The goal is to make project-management work **more structured, evidence-based, and reviewable** — not to automate professional accountability.

## Disclaimer

These materials are reusable professional-development templates. Adapt them to the specific project and follow applicable organisational, security, contractual, legal, and regulatory requirements.

> **Use AI to improve project thinking — not to outsource accountability.**
